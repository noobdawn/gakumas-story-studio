# 代码 UI 与合成变换

2026-11-18。代码 UI 使用现有 `ui` 轨道，片段保存 `uiKind: code` 和 `codeUI: {html, css, js}`。添加 UI 面板提供“添加代码 UI”，选中片段后在属性中编辑三段代码并应用，支持撤销、保存、复制与分割。游戏 UI 转场仍保留原入口和资源语义。

HTML 是 body 内容，CSS 可设置布局；JavaScript 定义 `render(time, duration)`，时间单位秒，按片段局部时间和源偏移采样。代码应直接从时间计算画面；不支持依赖定时器、随机数、外部网络或跨帧累积状态的动画。CSS 动画被暂停并采样同一时刻。HTML 中的 script 标签不执行，脚本写入 JS 属性。支持内联 data URL 图片／字体，不提供网络、文件、Node 或编辑器桥接 API。

Electron 在独立 sandbox、无 preload 的隐藏画布中渲染透明 PNG。CSP、请求与权限限制用于隔离作品代码；5 秒超时销毁画布并报告错误，下次可恢复。当前位图路线限制单图 300 KB、各段源码 100000 字符、最长边 1920；沿用状态传输／导出队列的总字节上限，超限明确报错。多条复杂 UI 会增加采样与传输开销，未承诺任意网页兼容或原有整片导出速度。

## 预览取样与导出

作品可选字段 `codeUISampling` 接受 `auto`、`dynamic` 或 `static`，省略时采用自动识别。自动模式只把无脚本、使用简单文字标签、常规属性和无资源声明的样式视为静态。含 CSS 动画、at-rule、函数、图片或脚本的片段按时间供帧。显式静态使用该片段的源起点，显式动态使用当前片段局部源时间。分割后的右段沿用原有源偏移，渲染函数的时长参数包含源偏移。

工作台以三段源码的 SHA-256、实际宽高、源时间和时长定位透明 PNG，命中后直接随合成消息送入 Player。位置、缩放、蒙版与透明度在组装图层时计算。相同内容的复制片段可共享采样。预览缓存仅存于当前工程会话的内存，容量上限为 32 MiB 的 base64 内容及 2,048 个条目，最近访问的帧优先保留。

输入结束 650 毫秒后，从播放头向前准备 5 秒、向后补 1 秒，依工程帧率在启用图层之间分批交替。后台每次最多渲染一帧，播放、指针拖动、代码编辑、切换工程和导出会让后台停下。编辑超时或容量不足时仍可实时渲染缺帧。Chromium 最多保留两块按源码与尺寸分配的离屏画布，后台取样被打断时可释放被占用的画布。正式导出绕开预览帧表，使用导出宽高与工程帧率从源码取样。

PNG 随当前帧合成消息传入 Player，校验尺寸后载入 sRGB RGBA 纹理，在 Linear 合成中参与层序、指定片段／UI 类别效果以及最终视频输出。不存在固定覆盖在最终画面之上的 DOM 预览层。结束片段后释放 Player 对应纹理；应用退出关闭隐藏画布。

所有画面片段提供 `compositionLayout: {x,y,scale,width,height,opacity}`，默认 `0,0,1,1,1,1`。位移按画布比例，原点为中心，Y 向上；宽高缩放与整体缩放相乘，透明度范围 0–1。变换在图片／视频自身裁剪布局、字幕原排版之后应用；接缝转场分别变换左右输入。演出世界是连续输出轨而非普通片段，其变换在“演出画面”轨道菜单中设置。

滤镜／特效的同名变换控制画布上的矩形作用区域和效果混合权重，保留区域外画面；在下方合成、指定片段和类别范围均生效。它不会移动被处理的原始画面。画面片段保留旧布局字段，未设置新变换时输出保持兼容。相机、角色骨架动作、场景切换与声音轨属于控制／声音轨，不是单独的屏幕合成图层。

`creator-code-ui-v1` 标记确认 Player 支持新节点与变换，旧 Player 提示更新。编译、人工 GPU 检查与隐藏作品预览分别记录，不能替代用户可见验收。
