## 复现入口

常规开发验证使用 `scripts/update-build.ps1`；仅桌面/宿主变更且 Player 对应的 Unity 源码未变化时使用 `-ReusePlayer`。脚本在隔离数据目录运行检查，隐藏布局测试的配置随临时构建目录清理。完整命令与输入要求见[单 build 工作流](local-builds.md)。

本地结果保存在 `.local/last-build-report`，该目录不提交。GitHub 托管的 Checks 当前执行源码、Node 和 Python 检查；隐藏布局与 Unity 构建结果不可由普通 CI 成功推断。
