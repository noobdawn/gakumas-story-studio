# 首次使用

当前为 Windows 发布候选。将便携包完整解压到可写目录后运行 `GSS.exe`；不要只复制这个 exe，也不要放入游戏安装目录。候选尚待实际界面与完整视频导出验收。

1. 选择创作器数据目录和已安装的游戏目录。作品、通用素材、声库和转换缓存保存在数据目录，游戏目录只读。
2. 选择 VOICEVOX 并勾选需要的声库，阅读上游条款后下载；也可暂时跳过，使用导入的音频。GPT-SoVITS 目前仅支持已有本地配置。
3. 在游戏资源步骤完成扫描与解包。失效或缺失缓存会返回准备入口；游戏更新后重新校验，不混用旧批次。
4. 完成向导进入工作台，新建工程或显式打开已有工程。首次不会自动加载开发者的演示工程。

使用时间轴安排角色、对白、动作、图片、视频和声音。保存工程时选择自己的作品路径；项目 JSON 与数据目录中的媒体引用应一起备份。导出前先用短片核对画面、声音和时间轴。

剧本中的回忆可使用黑白滤镜并为配音添加轻微回声，心理活动可使用暗角；具体入口与参数见[回忆与心理活动](story-filters.md)。

通用制作人预设会按资源修订安装，用户的修改或主动删除不会被覆盖。首次选择新数据目录只接受空目录，不自动搬移现有作品。开发者可通过 `scripts/start.ps1 -DataDirectory <已有目录> -Project <工程文件>` 显式使用已有数据；先备份工程再试候选。

当前可见预览、字幕观感、实际拖放和完整导出由使用者验收。UI 转场空白拖入、多素材批量拖入、图片与视频接缝转场拖入尚未实现。

## 时间轴拖入图片和视频

把素材浏览器中的视频或图片拖到目标行。悬停时可看到目标轨道名和对齐到帧的落点时间。

| 释放位置 | 时间轴结果 |
| --- | --- |
| 画面轨有足够的空位 | 放在该轨，沿用这一层的布局。片段从鼠标指向的时间开始。 |
| 新片段的时长与该轨已有片段重叠 | 在该轨正上方插入一条画面轨。新片段保留落点时间，原片段保留排时和层序。 |
| 相机、声音或其他类型的轨道 | 在所指轨道正上方新建画面轨。拖到左侧轨道名时使用当前播放头时间。 |
| 轨道列表下方的空白 | 在演出画面上方创建画面轨。如果工程没有演出画面，就放到轨道列表末尾。 |

也可以直接从文件管理器拖入单个视频或图片。选择导入范围后，创作器会按刚才的落点放置。视频使用实际源时长，超出演出结尾的部分会裁短。有声视频同时添加关联声音，同一画面层上的后续视频会复用有空位的关联声音轨。

要调整视频或贴图的位置，把播放头移入片段，在「画面 → 基础」中直接拖动预览里的画面。播放中按住会暂停，松手会继续播放。一次撤销恢复整次拖动。

删除最后一个片段时，对应的空轨会立即清除。一次撤销会恢复片段、关联声音和原轨道顺序。打开旧工程时也会清理空轨。「演出画面」持续显示相机输出，始终可以独立作为合成层存在。

## 移动已有片段

按住时间轴里片段的中部，拖到另一条轨道再松开。比如把第一条画面轨上的 A 视频垂直拖到第三条画面轨，目标行会高亮并显示落点时间。上下移动可保留原起点，同时左右拖动可调整起点。靠近时间轴上、下边缘会滚动，按 Esc 可取消。

目标画面轨在该时段有空位时，视频或图片直接移入。遇到已有片段，或指向其他类型的轨道时，创作器在目标正上方放置一条画面轨。片段已有的位置、缩放、裁剪、速度与关键帧随片段保留。关联声音随画面保持同步，原轨清空后会自动移除。按 Ctrl+Z 可一次恢复。

声音、字幕、动作、表情、UI、滤镜等片段可移到兼容的同类轨道。来源或目标锁定、角色缺少所需的通道、剧情主线控制排时等情况会显示原因。一起移动同轨相邻的两个画面片段可保留接缝转场，只移走一侧会解除这道接缝。

## 复制与粘贴片段

在时间轴选中一个或多个片段，按 **Ctrl+C**，把播放头移到需要的位置后按 **Ctrl+V**。落点已有片段时，创作器在原轨向后寻找所有成员都放得下的第一个位置。播放头停在原片段内也可以直接粘贴。关联视频和原声会一起复制，副本拥有自己的联动关系，一次撤销可移除整组副本。工程末尾空间不足时会随粘贴延长，最长一小时。编辑台词或数值时快捷键作用于当前输入框。

## 时间轴片段属性

单击时间轴上的片段，在右侧查看其属性。**表情素材**显示实际使用的表情名称、原始资源名和类型。点击 **更换表情…**，可以按中文名或原名搜索完整表情、单项形变和贴花／特效。选好后点击 **应用到片段**。自动生成的片段名随新素材更新，手动起的名字保留。起止时间、剧情绑定、权重关键帧和渐变沿用原设置，新素材从头取样。点击 **定位到片段中点** 可以在当前镜头查看效果。

| 片段 | 可以查看或修改的内容 |
| --- | --- |
| 表情与口型 | 完整表情可设源起点、循环或播放后保持末帧。形变与贴花可调权重及关键帧。对白口型显示模式和关联对白，音量口型可换嘴形，五元音可逐项换嘴形、调整各自的权重曲线。 |
| 身体动画 | 可查素材原名、类型、源时长，更换动作，调整源起点、循环和渐变。基础轨可选择源动画结束后保持末帧或恢复常驻动画。叠加轨另有混合方式、部位和权重。 |
| 场景 | 显示当前场景和原始资源名，可在同一片段更换场景。 |
| 音乐、音效与视频声音 | 在「音频」中可调音量、静音、淡入淡出和声音效果。选视频或它的关联原声都可以变速。独立声音可更换素材。 |
| 图片与视频 | 可查当前文件、尺寸和视频源时长，更换素材，修改布局、裁剪、关键帧和合成变换。视频支持源起点、速度、循环和声音联动。已有接缝转场可从任一相邻片段打开。 |
| 相机与对象变换 | 可看目标对象，编辑位置、旋转、相机 FOV 或角色／道具缩放，也可设置相机启用或对象显示的关键帧。 |
| 对白与字幕 | 可编辑说话人、台词、字幕样式、逐字显示、姓名条颜色及布局。关联音频提供音源、语气、已有音频、语音生成和口型模式。剧情主线中的对白通过排时入口调整时间。 |
| UI 叠加 | 游戏转场显示当前画幅使用的素材、源时长和遮挡区间，可切换转场。代码 UI 可编辑 HTML、CSS、JS 和源起点。两类均提供合成变换。 |
| 滤镜与特效 | 可查看算法，编辑启用状态、作用范围、强度、专用参数、渐变及合成变换。旧版通用效果可查看保存值，替换为专用算法后使用新版参数。 |

选中组合或多个片段时，可以在 **查看单个片段的完整属性** 中打开一个成员。展开 **片段信息** 可查所属轨道、起点和时长。普通片段可在下方调整剧情时间绑定。

- **画面 → 基础** 可调整图片、贴图、视频、拍摄镜头、字幕和可见 UI 的构图。「演出画面」轨道选项决定相机输出的默认布局。在拍摄片段调位置、缩放、裁剪或透明度，只影响该镜头。点「恢复轨道布局」可以重新继承默认值。改机位、朝向和视角请打开「镜头」。
- **画面 → 蒙版** 可添加线性、镜面、圆形和矩形蒙版。在预览里拖动青色手柄，或输入中心、角度和羽化量。镜面可调两边间距，圆形和矩形可解锁宽高比，矩形另可调圆角。多个已启用蒙版取交集。返回「基础」即可继续移动画面。
- **音频** 直接编辑所选视频的关联原声，或对白当前绑定的配音。0 dB 是原音量，静音保留已设音量。淡入、淡出以秒为单位，声音效果按列表顺序应用。
- **变速** 显示新旧时间轴时长。取视频第 6 至 14 秒，从 1× 调到 2× 会把画面和原声一起缩到 4 秒。改回 1× 恢复 8 秒，片段起点和所取的源区间保持一致。慢放需要轨上有足够空位和工程时长。静态贴图通过片段时长控制停留时间。

## 拍摄镜头预览缓存

把播放头停在拍摄片段内，时间轴标尺下的细线会标出就绪区间。再次播放或逐帧定位时，工作台在这些帧复用拍摄底图，继续实时合成上方的视频、贴图和字幕。移动贴图或调整音量可沿用底图，修改机位、动作或表情会从受影响的位置重新准备。关闭创作器会清理本次缓存。正式导出按工程画质重新渲染。

## 代码 UI 预览缓存

使用 HTML、CSS 或 JavaScript 制作的 UI 片段会自动缓存透明画面。把播放头停在想预览的片段附近，预览栏会显示「正在缓存 UI」，完成后显示「附近 UI 已缓存」。此时可以播放、回拖或逐帧查看。播放头前方默认准备 5 秒，后方准备 1 秒，多个重叠片段分别取样。长片段可将播放头停在下一段继续准备。「UI 已部分缓存」表示部分帧仍需在播放时计算。

默认「自动识别」适合多数片段。简单的纯文字卡片可以复用一张图，带脚本或 CSS 动画的片段按时间取样。要让带脚本的标题卡也固定显示，选中片段，在属性的「UI → 取样方式」中选择「静态 · 固定源起点画面」，点击「应用代码与取样」。需要逐帧求值时可选择「动态 · 按帧取样」。取样方式随工程保存，复制与分割会继承。

移动、缩放或调整片段透明度时可以沿用已准备的图像。修改 HTML、CSS 或 JS 后会按新代码取样。切换工程会释放预览缓存，导出会按实际输出尺寸计算 UI，所以基于画布宽度的 CSS 能适配 720p 和 1080p。

## 渲染与角色物理

打开「设置 → 工程设置 → 渲染设置 → 角色与物理」，在「物理方式」中直接选择。**新建工程默认 Hybrid**。一个工程中的角色共用这个选择，预览和导出都会使用它。

| 物理方式 | 画面表现 |
| --- | --- |
| 无 | 只播放角色动画，适合查看动作本身。 |
| GSS | 使用经典骨链、通用摆角和碰撞修正，可用来复现早期作品的摆动。 |
| Quartz | 衣摆和发束按模型作者设置的驱动、限位与骨链连接摆动。 |
| Hybrid | 保留 Quartz 的衣摆与后发摆动，额外收敛刘海和鬓角。适合前发在抬头或转身时甩得过高的镜头。 |

物理方式可以撤销、重做并随工程保存。打开只保存物理开关的旧工程时，原先开启会选中 Quartz，原先关闭会选中无。要在旧作品中采用 Hybrid，可以手动选择后保存工程。

描边和眼部高光也在「角色与物理」。场景阴影、角色发影和环境遮蔽在「光照与阴影」，环境反射和屏幕空间反射在「反射」，曝光、泛光和抗锯齿在「后期与画质」。「恢复画质默认值」作用于光照、反射、后处理、抗锯齿和眼部高光。物理方式单独选择。

## 视频导出方式

原生图层合成工程的导出窗口默认选择「GPU 加速（NVIDIA）」，需要支持 NVENC 的 NVIDIA 显卡及兼容驱动。设备不支持或 GPU 导出报错时，可选择「兼容模式」重新导出；旧版合成工程使用兼容模式。两种方式都使用工程的时长、帧率与比例，分辨率仍可选择720p或1080p。GPU加速只在导出期间解除帧率限制，结束或取消后恢复预览设置。

## 抗锯齿与导出超采样

「设置 → 工程设置 → 渲染设置 → 后期与画质 → 抗锯齿方式」可选关闭、FXAA、SMAA High、MSAA 2×、MSAA 4×、MSAA 8×、MSAA 4× + SMAA High。选择随工程保存，同时用于预览和导出。旧工程缺省时使用 SMAA High。

「工程设置 → 导出」和「导出视频」窗口均可设置超采样：关闭或 2×（宽高各两倍）。开启后，1080p 世界画面先按 3840×2160 渲染再缩回 1920×1080；字幕与界面保持输出尺寸和原图层顺序。GPU 加速与兼容模式都支持，最终分辨率及帧率不变。该选项独立于抗锯齿方法，默认关闭；开启会增加显存与渲染负担。

已知画面差异：MSAA 下部分树叶透空区域会变实，当前版本保留这一表现。TAA 尚未作为设置开放。

## 翻译提示词与发音词表

编辑器随版本提供完整日语翻译提示词和 180 条 VOICEVOX 发音替换词。缺少个人配置时自动使用默认值；后续更新保留你自行保存的设置，包括空词表。可在「设置 → 编辑器设置」分别恢复默认提示词或默认词表，再点击对应保存按钮。恢复提示词保留已填写的 API Key；密钥仍由你自行配置，不随版本提供。词表更改只影响之后生成的配音。


## 查看准备进度

语音和游戏资源各有独立进度条。语音下载显示当前文件序号、已下载大小和百分比；校验、解压、安装时显示当前阶段及活动状态。游戏准备依次显示扫描、解包、Player 资源、2D 场景、面部特效、音频库解码、Unity 音频解码和结果检查；进度按阶段估算，不代表剩余时间。取消、失败或部分完成会显示对应状态和说明。

初始化向导的上一步、下一步和完成按钮位于底部；中间内容可以滚动。游戏资源步骤优先显示解包操作，「目录与缓存详情」展开后可检查保存位置和空间占用。准备失败时先阅读状态和明细，再决定重试或调整目录。

## 窗口与高 DPI

向导、设置及工作台使用可滚动的内容区，控件按字号留出文字空间。窗口会按所在显示器的可用区域调整；工作台面板拖到最小操作尺寸后，空间不足时可滚动工作区访问其余面板。

实际 4K 屏幕、Windows 高 DPI 和跨显示器显示仍在验收。反馈文字裁切时，请附窗口大小、屏幕分辨率、系统缩放比例、所在页面及具体控件名称；不要附带 API Key 或完整游戏素材。
