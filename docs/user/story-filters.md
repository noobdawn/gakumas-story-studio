# 回忆与心理活动

素材浏览器与“添加滤镜”提供“回忆”和“心理活动”。把滤镜放在需要处理的画面层上方、字幕层下方，默认作用范围为“下方画面”。属性面板可调参数和起止时间，支持停用、淡入淡出、撤销与保存。

- 回忆：默认完全黑白；“黑白程度”可调整去色量，高光晕染默认关闭。声音需另外在对应声音片段上添加“回声”。轻微回忆感可从延迟 0.12 秒、反馈 0.15、干湿比 0.14 开始试听。
- 心理活动：中央保持清晰，四周柔和压暗。中心范围默认 0.35，边缘柔和度 0.55，边缘压暗 0.65；均可调整。
- 回忆中的心理活动可以叠加两条滤镜。字幕放在滤镜之上时保持原色与亮度。

声音效果不改写原始配音文件；预览与导出共用处理链。回声尾音在声音片段结束处裁断，效果不会自动延长剧情。

此次更新将回忆 `tone` 参数的含义改为黑白程度，旧工程原参数仍可加载，但回忆观感会由褪色暖调变为去色。新增心理活动需要当前 build 的 Player；不支持它的旧 Player 会明确报错。

这些效果为创作器实现。编译和人工纹理离屏检查不能替代实际工程画面、试听与导出验收。
