# 在文件中编辑提示词和替换词

打开「设置 → DeepSeek 与提示词」或「设置 → 发音替换」，点击文件路径即可使用系统默认编辑器打开。没有关联编辑器时可点「在文件夹中显示」，再用记事本、VS Code 等打开。文件位于当前创作器数据目录，适用于全部工程。

| 文件 | 编辑方式 | 生效时间 |
| --- | --- | --- |
| `translation-prompt.txt` | UTF-8 纯文本，可直接写多行；1～12000 字 | 保存后下一次翻译 |
| `pronunciation-replacements.json` | 修改 `rules` 数组中的 `from` / `to`；保留 `format` 和 `version` | 保存后下一次 VOICEVOX 配音生成 |

替换词示例：

```json
{
  "format": "creator-pronunciation-replacements",
  "version": 1,
  "rules": [
    { "from": "制作人", "to": "プロデューサー" },
    { "from": "莉波", "to": "りなみ" }
  ]
}
```

最多 200 条；原词不重复，每项最多 100 字，不含换行。空数组 `[]` 表示停用全部替换。格式有误会显示错误并停止相关翻译／配音操作，修正文件后再试。已有译文、字幕和音频不会自动重写。

设置页仍可编辑草稿。外部修改文件后，点「从文件重载（覆盖当前草稿）」即可刷新；若直接保存旧草稿，会提示文件已修改，避免覆盖外部工作。恢复默认仍先更新草稿，保存后生效。

升级时仅创建缺少的文件：提示词从已有设置保留，词表沿用原文件；已经存在的自定义文件不会被替换。API Key 仍加密存于 `deepseek-settings.json`，不需要编辑或复制密钥。该 JSON 中的 prompt 是旧格式兼容值，实际提示词以 `translation-prompt.txt` 为准。

# 颜色选择与屏幕取色

点击姓名条颜色后打开独立颜色窗口，可移到主程序外，并覆盖 Unity 预览。支持色相、饱和度／亮度、十六进制输入与「从屏幕取色」。应用颜色时写入工程，取消保持原值。

屏幕取色会暂时定格各显示器画面，可选择预览、桌面或其他应用中的像素。单击取色，Esc 或右键取消；取完回到颜色窗口确认。屏幕画面只在取色过程中使用，不写入文件。可见桌面的多屏、DPI 和 Unity 遮挡效果仍需实际设备验收。
