# 从标记剧本到演出工程

2026-11-19 整理。这里记录 `gss-script-to-project` 在 V04 至 V06 试作中形成的编排方法。先从标记稿找出发言者、在场角色、心理活动、换场和需要留给声音或画面的停顿。用稳定的剧情单元标识把这些安排系在对白上，等配音确定后再校准句中的动作和表情。[可复用的 GSS 剧本制作技能](../../skills/gss-script-to-project/SKILL.md)

## 让一句话里的想法演得出来

逐句读出台词的意图，找出角色改口、听懂、犹豫或下定决心的词和停顿。身体与脸可以分别起动，也可以跨字幕延续。下面用一段假设对白试排手毬从思考到质疑、再做决定的过程。

| 台词的变化 | 身体 | 表情与视线 |
| --- | --- | --- |
| 她说想再想想 | 略低头，维持思考姿势 | 垂眼，眉心微收 |
| 话到一半发现时间对不上 | 在意识到矛盾时抬头，手势可以接着上一句 | 先抬眼，到说出矛盾的词时才蹙眉 |
| 停顿后决定亲自确认 | 在停顿里收手，说出决定时面向对方 | 目光定住 |

心理独白默认选角色可用的思考动作和思索表情，通常闭口，让眼神和眉部跟随念头。念头在哪一拍转为惊慌、愤怒或坚定，就在哪一拍改变表演。若一开始已经慌了，可以直接从惊慌演起。2D 立绘按同一转折换已有表情差分。心理活动沿用暗角，回忆中的独白可以叠加黑白回忆效果。

角色保持手势时，在基础姿势或进入动画的末态上持续叠加相容的原生律动。当前 GSS 可将增量身体层设为 `condition: always`。抽查保持段中两个不同的呼吸相位，观察身体起伏和手势是否连贯，再连播到下一句检查收势。

句中动作和表情可各自绑定到本句语音起点。保留片段关键帧时，绑定写作 `storyTiming = {start: {unitId, edge: "speechStart", offset: t}, keys: "keep"}`。按最终日语实际说出触发词的时间量取偏移 `t`，单位为秒。动作需要蓄势时可提前起手，让观众看见的反应落在重音上。重新合成后，先按新音频时长重排，再复听并校准句内偏移。

回看一段连续发言和一段心理独白，在触发词前后观察人物。若听得出她改了主意，画面却只有呼吸和口型，就在那一拍补一个当前景别能看清的反应，例如移开视线、收回伸出的手。

## 换场与信息弹窗

跨时间、地点或谈话场合时安排转场，进出回忆也计入。同一教室隔了几天可用时钟，转到另一场会面可用条带。把场景、出镜角色和滤镜的切点藏在全遮挡的画面里，揭开后再显示日期。连续对话里的正反打可直接切镜，原稿明确要求硬切的段落照稿执行。

横屏剧情保留人物作为视觉重心，用半透明底和清楚的字号层级承载信息。左上弹窗采用「亲密度／第1话」式样，半透明灰底，左端平直固定，右端圆弧，上小下大两行白字。面板从左向右展开，完整停留后反向收回。可从 0.5 秒展开、3 秒停留、0.5 秒收回开始试排。动画裁切面板和文字的可见范围，保持字形稳定。[游戏官方教程画面](https://gakuen.idolmaster-official.jp/assets/img/road/accordion_img_3_1.png)

在 UI 轨添加代码 UI，选中片段即可在属性里编辑 HTML、CSS 和 JS。用 `render(time, duration)` 按片段本地时间驱动展开，跳回同一帧时能复现相同宽度。UI 参与画面层序，可被上方转场遮住。合成片段可调位置、整体与宽高缩放、透明度。连续的「演出画面」在轨道菜单调整，滤镜的这些参数控制作用区域和混合强度。[代码 UI 与合成变换](../developer/code-ui.md)

## 日语配音与日常音效

中文字幕保留英文原拼写，给 VOICEVOX 的朗读文本使用假名。先查当前发音替换表，例如 `SyngUp! → シングアップ`。未收录的选手 ID 查日语实况称呼，作品专名查原作口播或注音。检查实际送入引擎的文本，包括全角拉丁字母。本次采用的读法包括 TeSeS「テセス」、flameZ「フレイムジィ」、XANTARES「ザンタレス」和 NiKo「ニコ」。全剧重新 Cook 时逐句合成有声对白、保留纯停顿，并按新音频更新口型。[发音替换词与默认配置](../../resources/editor-defaults/README.md)

六项日常音效已登记到本机「通用素材 → 音效」。敲门、开门、关门、钥匙开锁和门铃取自当时的受管理游戏批次。手机在木桌上震动取自 GallerShades 的 CC0 实录。按角色做出或听见动作的时刻落声音，例如先敲门、留三秒等回应，再开锁、开门。[手机震动录音与来源](https://freesound.org/people/GallerShades/sounds/83704/)

## 轻松对白的选曲依据

本次从 4,051 份游戏剧情脚本中找到 7,051 次有名称的 BGM 播放指令。把 414 个音频变体归为 230 首，其中 138 首查到剧情调用，71 首匹配到日文曲名。选曲时并列记下原作在哪一幕调用，以及新剧本打算在哪句话进、哪句话收。只有资源名可参考的曲目标明依据。[官方原声带曲目表](https://gamemusic.bn-ent.net/release/680/)

| 曲目与素材标识 | 查到的原作使用情境 | 轻松对白中的用法建议 |
| --- | --- | --- |
| 生徒たちの日常 · `adv_daily-001` | 美铃接受邀约，与制作人约定慢慢来 | 用在平常的开场，门外第一声敲门前收掉 |
| トラブルメーカーズ · `adv_comical-002` | 制作人认真打听让天气变阴的咒法，老师吐槽 | 在荒唐的细节揭晓时进乐，反问前切空 |
| 夕暮れ時 · `adv_evening-001` | 美铃和手毬感谢制作人帮忙搬家、办理宿舍同住手续 | 托住晚间等待的对话，等到消息出现时淡出 |

这次为 14 段剧情标记配乐或留白，筛出 12 首候选并做了 3 段带对白的试听。门外等待、需要听清插入视频和阅读截图的段落都可以留白。选曲表供剪辑时取舍。
