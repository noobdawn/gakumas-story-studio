# 随版本提供的编辑器默认配置

`defaults.json` 是唯一默认数据源：完整中日翻译提示词和 180 条 VOICEVOX 发音替换词。`manifest.json` 记录修订、数量和 SHA-256，构建时校验并随便携包提供。修改默认配置时同步更新清单。

来源为 2026-11-09 已应用且读回核对的参考表更新版本；用户于 2026-11-15 指定这两项与制作人预设一样随代码分发。本次原样恢复，提示词保留角色风格、术语、条件称呼及原创角色说明，其中创作约定与候选读音不等于官方事实或逐条听审结果。

首次使用或配置缺失时读取此默认值；已有用户提示词、自定义词表和主动保存的空词表优先，不会被版本更新覆盖。设置页的恢复默认按钮先更新编辑草稿，保存后生效。词表只影响新生成的语音，不改已有译文、字幕或音频。

此目录仅包含公共提示词与词表，不收录 API Key、密钥密文、个人路径或作品。密钥保存在用户数据目录中；恢复默认提示词不会清除或重写密钥密文。

2026-11-17 起，启动时仅补齐缺少的 `translation-prompt.txt` 和 `pronunciation-replacements.json`；提示词优先保留旧设置中的自定义内容。外部保存后下一次操作读取，编辑说明见 [文件配置](../../docs/user/editable-settings.md)。
