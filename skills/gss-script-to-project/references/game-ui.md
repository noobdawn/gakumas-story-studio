# 《学园偶像大师》UI 截图与演出做法

## 画面依据

- 主页实截图中，人物占据中央，左右的单色图标和小标签分布在边缘。浅色圆角按钮、细描边和小块高亮能从场景里分离出来。下方弧形导航属于交互界面，横屏剧情只取它的材质和信息层次。[主页实截图与原作者说明](https://note.com/col_loc/n/n4d5dc52d92c7)
- 官方教程的课表和授课选择画面用颜色区分动作或重点，主要信息可通过形状和文字直接辨认。图中的橙框、粉色圈注属于教程排版，做剧情 UI 时依据其中的游戏画面。[官方训练画面](https://gakuen.idolmaster-official.jp/assets/img/road/accordion_img_2_1.png) · [官方授课选择画面](https://gakuen.idolmaster-official.jp/assets/img/road/accordion_img_3_1.png)
- 制作人小美野日出文说明，主页的磨砂玻璃质感意在拉近玩家和偶像的距离，局部配色随偶像变化。[制作人访谈](https://dengekionline.com/nintendo/article/202404/1765)

## 横屏剧情中的用法

用户提供的「亲密度／第1话」截图决定左上信息弹窗的样式。半透明烟灰色面板左端平直，右端为半圆形；上行是较小的白色类别，下行是较大的白色正文。日期或时段照写原稿。回忆场可用「回忆」作上行提示。横屏可从左 4%、顶 6%、面板宽高约 4:1 开始试排。其他交互图形仍可依据主页实截图使用浅色玻璃和局部角色色。

同组日期牌采用一致宽度，为较长日期留足空间，并检查与头顶、视线和对白框的间距。顶端标签要在最亮与最暗的实际镜头都能读清。代码 UI 在独立透明表面渲染时，半透明填充能直接露出场景背景。

左边缘固定，动画驱动面板的可见宽度；正文固定字号、按面板边界裁切。默认用 0.5 秒向右伸出、3 秒完整停留、0.5 秒向左收回，按剧本节奏可调。JS 从片段本地时间计算宽度，以便反向拖动时间轴也能看到正确状态。抽查伸出中、两个停留时间点、收回中及完全收回后，确认停留稳定、方向正确。

叙事换场放在日期牌上方，用全遮挡区覆盖场景切点，在揭开后的新场景显示日期。回忆的黑白效果作用于故事画面，日期牌和对白保留可读对比度。抽查转场前、全遮挡、揭开后三帧，并检查日期最长的一张、对白同屏和回忆返回处。
